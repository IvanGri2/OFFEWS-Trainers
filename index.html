Четыре шага до бессмертияFour steps to god mode

  1. СкачайDownload

    Один exe-файл, устанавливать ничего не нужно.A single exe, nothing to install.

  2. Запусти трейнер и игруStart trainer and game

    В любом порядке: трейнер сам найдёт игру.In any order: the trainer finds the game.

  3. Дождись «подключено»Wait for “connected”

    Статус внизу окна. Загрузи сохранение или главу.Status is at the bottom. Load a save or chapter.

  4. ВключайSwitch on

    Кликом в окне или горячей клавишей прямо в игре.Click in the window or press a hotkey in game.

ВопросыFAQ

Частые вопросыCommon questions

Антивирус ругается на трейнер. Это вирус?My antivirus flags the trainer. Is it a virus?

Нет. Трейнер меняет память игры, и некоторые антивирусы по эвристике считают это подозрительным. Обычно срабатывает один антивирус из семидесяти. Трейнер ничего не скачивает, не устанавливает и не отправляет в сеть.No. The trainer changes the game’s memory, and some antivirus heuristics find that suspicious. Usually one scanner out of seventy reacts. The trainer downloads, installs and sends nothing.

Можно ли играть с трейнером по сети?Can I use a trainer online?

Нет. Трейнеры сделаны только для одиночной игры. Если трейнер видит античит или сетевую игру, функции не включаются.No. The trainers are for single-player only. If a trainer detects an anti-cheat or an online session, functions stay off.

Игра обновилась, и трейнер перестал работатьThe game updated and the trainer stopped working

Сравни версию игры в окне трейнера с проверенной. Если они различаются, дождись обновления трейнера.Compare the game version in the trainer window with the tested one. If they differ, wait for a trainer update.

Трейнер не запускаетсяThe trainer does not start

Нужен .NET Framework 4.8. В Windows 10 и 11 он уже есть, в старых системах его можно поставить с сайта Microsoft.It needs .NET Framework 4.8. Windows 10 and 11 already have it; on older systems install it from Microsoft.

Не испортит ли трейнер сохранения?Can the trainer break my saves?

Функции меняют игру, только пока включены. Перед изменением денег, предметов и опыта на всякий случай сделай копию сохранений.Functions only change the game while they are on. Before changing money, items or experience, back up your saves just in case.
