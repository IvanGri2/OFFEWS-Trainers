End of Abyss cheats

The OFFEWS trainer packs 22 cheats for End of Abyss into one small program, with no mods and no changes to game files. God mode, unlimited ammo and heals, no reload or overheating, one-hit kills, frozen enemies, money, every weapon upgrade, flight and teleport.

Tested on build of 2026-10-03, mode: single-player. Download the exe, run it alongside the game and switch cheats on with a click in the trainer window or with hotkeys in game.

How it works

Four steps to god mode

  1. Download

    A single exe, nothing to install.

  2. Start trainer and game

    In any order: the trainer finds the game.

  3. Wait for “connected”

    Status is at the bottom. Load a save or chapter.

  4. Switch on

    Click in the window or press a hotkey in game.

FAQ

Common questions

My antivirus flags the trainer. Is it a virus?

No. The trainer changes the game’s memory, and some antivirus heuristics find that suspicious. Usually one scanner out of seventy reacts. The trainer downloads, installs and sends nothing.

Can I use a trainer online?

No. The trainers are for single-player only. If a trainer detects an anti-cheat or an online session, functions stay off.

The game updated and the trainer stopped working

Compare the game version in the trainer window with the tested one. If they differ, wait for a trainer update.

The trainer does not start

It needs .NET Framework 4.8. Windows 10 and 11 already have it; on older systems install it from Microsoft.

Can the trainer break my saves?

Functions only change the game while they are on. Before changing money, items or experience, back up your saves just in case.
